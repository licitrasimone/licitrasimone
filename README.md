# Hi, I'm Simone Licitra 👋

**Red Team Specialist · Penetration Tester · AI/LLM Security Researcher**

I work at **OPLIUM** in Turin, Italy, where I focus on offensive security, red team operations, penetration testing, and helping organizations improve their security posture through realistic adversary simulation and practical remediation.

I graduated in December 2024 with a **Master's degree in Computer Engineering from Politecnico di Torino**, where my thesis, *Leveraging AI Techniques for Automated Security Incident Response*, explored how AI can support SOC automation, incident response, and defacement monitoring.

My work sits at the intersection of:

- **Red Team Operations** — adversary simulation, C2 tradecraft, OPSEC, Active Directory attack paths
- **Penetration Testing** — web, API, mobile, infrastructure, and wireless assessments
- **AI/LLM Security** — prompt injection, jailbreak testing, agent/tool abuse, data leakage, and AI security automation
- **DevSecOps** — secure SDLC, pipeline hardening, SAST/DAST/SCA, and security-by-design
- **Security Research & Tooling** — building practical tools for offensive security and security automation

## 🔬 Current Research & Projects

### [AIX — AI eXploit](https://github.com/licitrasimone/aix-framework)
A security testing framework for AI/LLM systems, built to help penetration testers and red teamers assess AI endpoints for prompt injection, jailbreaks, system prompt extraction, data leakage, tool abuse, and agent exploitation.

### [CrystalSliver](https://github.com/licitrasimone/CrystalSliver)
A Crystal Palace evasion kit port for **Sliver C2**, bringing Crystal-Kit style tradecraft into a Sliver-focused workflow.

### [SOCAI Project](https://webthesis.biblio.polito.it/33833/)
My Master's thesis project on using AI techniques to automate and streamline SOC incident response workflows.
